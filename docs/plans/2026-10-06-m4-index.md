## Plan 12 / Plan 13 共享契约（协调者裁定，2026-10-06）

两份计划各自补全了设计未写明的细节，以下为唯一口径；与此不一致的计划文本以本节为准。

| # | 主题 | 裁定 |
|---|---|---|
| A | 等待用户回答 | Worker→宿主的独立最终提议 `awaiting_input{attempt_id, checkpoint_id, question_id}`（Plan 12 方案 + Plan 13 的 `question_id`）；任务状态为 `paused`、原因 `awaiting_input` |
| B | 续跑指令 | `task_start.directive` 取 `finish_now` 或 `answer{question_id, answers}`；**无 directive = 正常开始或继续**；不设 `restore` 指令 |
| C | 恢复（Restore） | 宿主把源 turn 最新 checkpoint 复制为新任务的种子 `seed-<id>`（Plan 12）；Worker 像崩溃恢复一样从种子继续；`task_start.restored_from_task_id` 仅用于展示；新任务获得新的 30 次额度 |
| D | 被取代 turn 的上下文（D5） | `task_start.carryover{task_id, checkpoint_ref}`：宿主给出被取消 turn 最新 checkpoint 的 blob 引用（已授权到会话 scope），Worker 经 Gateway 读取；缺失或损坏时新一轮不带上下文继续 |
| E | 工具额度信号 | `/v1/search`、`/v1/fetch` 响应头 `X-Agentbox-Tool-Budget: <used>/<limit>`，`/v1/budget` 同名字段；第 31 次 `429 tool_budget_exhausted`；在 Tx1 新建 `calls` 行时计数（缓存命中、合并也计数，重放不计） |
| F | 原始请求/响应（⟨/⟩） | 请求内联在事件中（≤32 KiB，带截断标记）；响应经 `GET /turns/{id}/raw/{sha}`（服务端脱敏）。**不使用** call_id 端点（call_id 是内部字段，用户不可见） |
| G | 事件类型 | Plan 12 Task 1 的 `SessionEvent` 列表须包含 Plan 13 的全部进度种类：`route`、`skill_read`、`thinking`、`ask_user`、`todo_updated`、`subtopic`、`tool_call`、`tool_result`、`assistant_delta`、`budget`、`report_ready`、`turn_stopped`；这些种类的 `data` 对会话所有者可见（只去除费用、模型价格与内部 ID） |
| H | 推理模型字段 | Gateway chat 校验接受 assistant 消息中可选的 `reasoning_content` 与 `tool_calls`，`content` 可为空串（Plan 12 Task 4 一并修改 `internal/gateway/upstream`）；Plan 13 Task 9 在真实 Kimi 上验证多轮工具调用 |
| I | 运行中再发消息 | `409 turn_in_progress`（无 FIFO 排队）；界面在运行中禁用发送并提示"先停止当前研究"；暂停或停止中的 turn 按 D5 被取代 |
| J | 会话标题 | 首条消息前 40 个字符（不调用模型）——对设计 D4"自动标题"的简化，可在后续改为模型生成 |
| K | Worker 命令 | 会话 Worker 为 `python3 -m chatagent`，经 `--session-worker-argv` 配置；未配置时会话端点 `503 sessions_unavailable` |

## 执行顺序（并行）

- 已在执行：P13-T2（工具包核心）、P14-T2（已合入）、P15-T1（沙箱加固，持有 root 测试权）、P15-T4、P15-T6。
- 下一批：P12-T1（API 与事件契约）、P12-T2（协议会话扩展）并行 → P12-T3 → P12-T4；P12-T1 合入后 P13 web 轨（T6→T7→T8）开始；P12-T2 合入后 P13-T1（SDK 会话模式）开始。
- P14-T1/T3 在 P12-T2/T3 合入后；P15-T7 在 0006、0007 合入后。
- root / 真实沙箱运行同一时间只允许一个 agent。
