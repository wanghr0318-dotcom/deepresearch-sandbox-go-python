# M3 Plan 11：用户账号体系（面向用户的 DeepResearch 助手）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现[用户账号设计](../superpowers/specs/2026-10-06-user-accounts-design.md)：开放注册（用户名 + 密码）、服务端会话、用户只见自己的研究、内部细节仅运维可见、每用户同时 1 个运行中任务；Vue 增加用户侧助手页，现有工作台移到 `#/admin`。

**Architecture:** 新包 `internal/account`（纯逻辑：密码哈希、会话 ID、校验、限速，无 I/O）；PostgreSQL 存用户与会话（migration 0005）并给任务加 `owner_user_id`；`internal/api` 在现有 Bearer 鉴权前增加"主体"（principal）解析：Bearer = 管理员，会话 cookie = 用户，二者都没有时只放行 `/auth/*`、`/status` 与静态文件；授权在 handler 内按主体过滤。用户提交只含主题，server 用固定模板补全 spec。

**Tech Stack:** Go 1.27 标准库（`crypto/pbkdf2`、`crypto/sha256`、`crypto/rand`、`crypto/subtle`、`net/http`）、PostgreSQL（pgx，已有）、Vue 3 + TS + Vitest（已有）。不引入新的 Go 模块或 npm 依赖。

**规格依据：** 设计文档全文；v0.2 规格 §15.1（OpenAPI 唯一契约）、§15.3（浏览器安全：Origin 允许列表）。

## Global Constraints

- 密码哈希：PBKDF2-HMAC-SHA256，迭代 600000，盐 16 字节随机，派生 32 字节；存储格式 `pbkdf2-sha256$600000$<base64url 盐>$<base64url 哈希>`（无填充）；比较用 `subtle.ConstantTimeCompare`。
- 用户名：3–32 位，`^[A-Za-z0-9_.-]+$`，唯一性大小写不敏感（存 `lower(username)` 唯一索引，展示保留原样）。密码：8–128 个字符（按 rune 计）。
- 会话：ID 为 32 字节随机数的 base64url（无填充）；库中只存 `sha256(id)`；有效期 7 天（`expires_at`），不滑动续期；cookie 名 `agentbox_session`，属性 `HttpOnly; Secure; SameSite=Strict; Path=/`；登出删除会话行并下发 `Max-Age=0`。
- `Secure` 属性：TLS 监听时设置；非 TLS 监听（仅 loopback 开发）不设置，否则浏览器不回传。
- 鉴权优先级：有 `Authorization: Bearer` 头时只按 Bearer 判定（无效即 401，不回退到 cookie）；否则看会话 cookie。
- 匿名可访问：`POST /auth/register`、`POST /auth/login`、`GET /status`、静态文件。`POST /auth/logout`、`GET /auth/me` 需要会话。
- 限速（每 IP，内存令牌桶，进程内）：注册 5 次/分钟、登录 10 次/分钟；超出 `429 rate_limited`。客户端 IP 取 `RemoteAddr` 的主机部分（不信任 `X-Forwarded-For`）。
- 登录失败一律 `401 invalid_credentials`，消息相同；用户不存在时也执行一次 `account.DummyVerify` 以消除时序差异。
- 用户可用端点：`POST /research`、`GET /tasks`（只含自己的）、`GET /tasks/{id}`、`GET /tasks/{id}/events`、`GET /tasks/{id}/result`、`GET /tasks/{id}/artifacts/...`、`POST /tasks/{id}/cancel`。他人任务与无主任务一律 `404 task_not_found`。其他端点（`POST /tasks`、pause/resume、inspect 等）对用户返回 `403 forbidden`。
- 每用户同时最多 1 个非终态任务：`POST /research` 在同一事务中锁定用户行（`SELECT … FOR UPDATE`）后计数，超出 `409 user_task_running`。
- 用户研究的 spec 由 server 生成：`{"topic": <主题>, "orchestrator_model": <--user-orchestrator-model，默认 kimi-k3>, "worker_model": <--user-worker-model，默认 kimi-k2.6>}`；limits 用 server 默认值；主题 1–500 个字符，去首尾空白。
- 会话 ID、密码、密码哈希不出现在日志、事件、错误消息与 inspect 中。
- 测试：Go 每包一个测试文件；需要数据库的用例读 `AGENTBOX_TEST_DATABASE_URL`，`CI=true` 时缺失即失败。
- 分支：集成分支 `m3-batch`；每个任务一个 worktree；运行验收串行。

```go
func HashPassword(pw string) (string, error) {
	salt := make([]byte, 16)
	if _, err := rand.Read(salt); err != nil {
		return "", err
	}
	key, err := pbkdf2.Key(sha256.New, pw, salt, Iterations, 32)
	if err != nil {
		return "", err
	}
	enc := base64.RawURLEncoding
	return fmt.Sprintf("pbkdf2-sha256$%d$%s$%s", Iterations, enc.EncodeToString(salt), enc.EncodeToString(key)), nil
}

func VerifyPassword(stored, pw string) bool {
	parts := strings.Split(stored, "$")
	if len(parts) != 4 || parts[0] != "pbkdf2-sha256" {
		return false
	}
	iter, err := strconv.Atoi(parts[1])
	if err != nil || iter < 1 || iter > 10_000_000 {
		return false
	}
	enc := base64.RawURLEncoding
	salt, err1 := enc.DecodeString(parts[2])
	want, err2 := enc.DecodeString(parts[3])
	if err1 != nil || err2 != nil || len(want) == 0 {
		return false
	}
	got, err := pbkdf2.Key(sha256.New, pw, salt, iter, len(want))
	return err == nil && subtle.ConstantTimeCompare(got, want) == 1
}
```

`DummyVerify` 用包级 `sync.OnceValue` 生成的固定哈希调用 `VerifyPassword`。Limiter：每键 `{tokens float64, last time.Time}`，容量 = perMinute，速率 = perMinute/60 每秒；超过 10000 个键时清理 1 分钟内未活动的键。

    id            bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    username      text NOT NULL,

type User struct {
	ID        int64     `json:"-"`
	Username  string    `json:"username"`
	Role      string    `json:"role"`
	Disabled  bool      `json:"disabled"`
	CreatedAt time.Time `json:"created_at"`
}

// Accounts 是账号与会话的存储（postgres 实现）。
type Accounts interface {
	// CreateUser 以 key 唯一；重复返回 persistence.ErrConflict。
	CreateUser(ctx context.Context, display, key, passwordHash string) (User, error)

**行为：**
1. 中间件：Origin 检查不变 → 有 `Authorization` 头：Bearer 校验（不变），通过即 admin → 否则读 cookie `agentbox_session`：`SessionUser(HashSessionID(v))` 命中即 user → 都没有：只放行匿名端点（Global Constraints 列表），其余 `401 unauthorized`。

4. `/auth/logout`：删除会话、`Set-Cookie` Max-Age=0 → `204`。`/auth/me` → `200 {"username","role"}`。
5. `POST /research`（仅 user）：body `{"request_id","topic"}`；主题校验（`400 invalid_topic`）；`ResearchSpec(topic)`；`CreateResearch`；`ErrUserTaskRunning` → `409 user_task_running`；成功 `202 {"task_id"}`。admin 调用 → `403 forbidden`（运维用 `POST /tasks`）。
