## 待审批的决定（随本索引一并审阅）

1. 默认预算 `--default-budget-micro 2_000_000`（2.00 USD）、上限 `50_000_000`；预算随任务存储于 `limits.budget_micro`。
2. 每 provider 全局在途上限默认 8（规格只说"每 provider 全局限额"）。
3. 无 Key 的演示搜索源 `ddg_lite`（脆弱，仅演示）；`tavily` 为可选的有 Key 源。
4. `task.Access` 接口变更：`Bind(ctx, attemptID, envID)`、`Revoke(ctx, attemptID, reason)`；actor 撤销顺序改为先持久化、再关连接（规格 §9.1）。
5. sub-run 层账本、exec 配额、`X-Agentbox-Subrun` 留到 M4；缓存留到 M3。
6. DeepResearch 接入方式：移植算法与提示词到零依赖的 `worker/deepresearch`，不把现有项目的 FastAPI/Milvus/torch/hello-agents 栈搬进沙箱。
7. 真实模型演示需要用户在演示时提供模型 base URL 与模型名（Key 已在 `F:\go-agentbox\.env`，只经环境变量读取）。
