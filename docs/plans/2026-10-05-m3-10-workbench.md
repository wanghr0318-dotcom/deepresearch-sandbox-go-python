# M3 Plan 10：Vue 工作台、下载端点与浏览器安全

> **执行方式**：同 Plan 9。前端任务在 Windows（Node 24、npm 在线）开发与测试；与 server 的联调在 WSL 串行运行。
> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development。

**Goal:** 实现规格 §15.3–§15.4：补齐 M1/M2 留下的结果与产物下载端点（目前 501），加固浏览器访问安全（Origin/Host 允许列表、token 不入 URL/日志/构建产物、可选 TLS），并把现有 DeepResearch 前端改造为 go-agentbox 工作台：任务列表、事件时间线、产物与版本、预算与调用明细、inspect；SSE 以 `fetch()` 读取并自行维护游标与重连，收到 `task_terminal` 后停止重连；报告 Markdown 安全渲染，HTML/SVG 产物只下载。

**Architecture:** 服务端是状态与权限的唯一权威；Vue 只维护交互与展示状态。TypeScript 类型由 `api/openapi.yaml` 生成（`openapi-typescript`），不手写 API 形状。前端放在 `web/`（Vite + Vue 3 + TS），构建产物由 `agentbox server --web-dir` 以静态文件同源提供（与 API 同一 Origin，不开 CORS）。浏览器侧 token：用户在页面输入，只保存在内存（刷新即丢）或 `sessionStorage`（可配置），只放在 `Authorization` 头。

**Tech Stack:** Go 1.23（`net/http` 静态文件、TLS）；Vue 3.5、Vite 6、TypeScript 5、`marked` + `DOMPurify`、`openapi-typescript`、Vitest + `@vue/test-utils`、Playwright（E2E，可选，若 CI 时间允许）。

**规格依据：** §15.1（OpenAPI 唯一契约）、§15.2（SSE：心跳 15 s、`task_terminal` 后关闭、续传游标）、§15.3、§15.4、§16.4 E16（Vue 部分）、E26、E27；§5.6（产物版本固定）；§9.9（不暴露凭据）。

## Global Constraints

- **同源**：工作台与 API 同一 Origin；不使用通配 CORS；`Origin`/`Host` 显式允许列表沿用 M1 的 `--allowed-host`，新增 `--allowed-origin`（默认等于监听地址）。
- **token**：不出现在 URL、日志、前端构建产物、`localStorage`；只在 `Authorization: Bearer` 头；`/status` 等匿名可读端点保持现状。
- **渲染安全**：报告 Markdown 经 `marked` → `DOMPurify`（禁止 `<script>`、事件属性、`javascript:` URL、`<iframe>`、`<object>`、`<style>`）后插入；产物 `text/html`、`image/svg+xml` 及其他主动内容一律下载（`Content-Disposition: attachment`），不内联。
- **类型**：`web/src/api/schema.d.ts` 由 `npm run gen:api` 从 `api/openapi.yaml` 生成并提交；CI 检查生成结果与提交一致。
- **测试**：Go 每包一个测试文件；前端 Vitest 单元测试 + 组件测试；工作台的 E16/E26/E27 以 Go e2e 驱动 server，前端行为用 Vitest 覆盖（Playwright 可选）。
- **分支**：同 Plan 9（`m3-batch`）。

### Task 1：下载端点

**Files:** Modify `internal/api/{http.go,store.go,api_test.go}`、`api/openapi.yaml`、`internal/persistence/postgres/apiread.go`、`internal/cli/cli.go`（`task result` 不再遇到 501）、`internal/app/adapters.go`（BlobStore 接入 api）。

**规则：** `GET /tasks/{id}/result`：任务终态且有 result → 返回 result JSON（含固定的输出 `(artifact_id, version, sha256)`）；否则 `404 not_ready`/`409 task_not_terminal`。`GET /tasks/{id}/artifacts/{artifact_id}`：默认最新版本，`?version=N` 指定；正文从 BlobStore 流式读取，`ETag` 为带引号的 sha256，`Content-Type` 为登记的 media type；主动内容类型强制 `Content-Disposition: attachment`。只读权限即可访问；授权按 `scope_blobs(task)`。CLI `task result` 下载并校验 sha256。

**Tests：** 版本选择；未终态/不存在；ETag 与 sha 一致；HTML/SVG 为 attachment；CLI 校验失败时报错（篡改 blob）；OpenAPI 契约测试（已有的 handlers-match-openapi 用例）。

### Task 2：浏览器安全与静态提供

**Files:** Modify `internal/api/{http.go,api_test.go}`、`internal/app/app.go`、`cmd/agentbox/server.go`、`api/openapi.yaml`（无变化则不改）。

**规则：** `--web-dir` 指定时 `/` 下提供静态文件（`index.html` 的 SPA 回退，只对非 `/tasks`、`/status` 等 API 路径）；响应头 `Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src 'self'; frame-ancestors 'none'; base-uri 'none'; form-action 'self'`、`X-Content-Type-Options: nosniff`、`Referrer-Policy: no-referrer`；API 请求校验 `Origin`（存在时必须在允许列表）与 `Host`；`--tls-cert/--tls-key` 可选，非 loopback 监听且无 TLS 时启动警告（不拒绝，规格要求"可信 TLS 终止"可在外部）。日志中间件不记录 `Authorization`。

**Tests（E26）：** 外部 `Origin` 的 POST 被拒；错误 `Host` 被拒；token 不出现在访问日志（扫描）；静态文件的安全头；SPA 回退不吞 API 路径；TLS 监听可用（测试证书）。

### Task 3：`web/` 工程、类型与客户端

**Files:** Create `web/`（`package.json`、`vite.config.ts`、`tsconfig*.json`、`index.html`、`src/main.ts`、`src/api/{schema.d.ts,client.ts,sse.ts}`、`src/api/*.test.ts`）。从 `F:\helloagents-deepresearch0527\frontend` 只迁入可复用的组件结构与样式（不复制其 `.env`、不复制其后端调用）。

**规则：** `client.ts`：`fetch` + `Authorization` 头；错误体（以 `api/openapi.yaml` 的 Error 为准：扁平 `{"code","message"}`）映射为类型化错误；提交与控制请求生成 `request_id` 并在重试时复用。`sse.ts`：`fetch()` 读取 `text/event-stream`，自行解析帧，维护 `Last-Event-ID` 游标，断线指数退避重连（上限 30 s），按事件 ID 去重，收到 `task_terminal` 后关闭且不再重连，`400 invalid_cursor` 时停止并报告。

**Tests（Vitest）：** SSE 解析（多行 data、注释心跳、分块边界）；断线重连从游标继续、无缺失无重复；`task_terminal` 后不再发请求（E16 Vue 部分）；`request_id` 重试复用；token 不进入 URL。
