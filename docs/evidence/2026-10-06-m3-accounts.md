> 日期：2026-10-06。宿主：腾讯云 CVM 上海五区（4 vCPU / 8 GiB，Ubuntu 24.04，内核 6.8），常驻服务 `agentbox-demo`（`deploy/systemd/agentbox-demo.service`：HTTPS 443、自签证书、serper、Redis、编排 kimi-k3 / worker kimi-k2.6）。
> 方式：从维护者本机经公网对 `https://49.235.41.14` 发请求（curl，cookie 存于本地临时文件）；运维侧在服务器本机以 Bearer token 访问（token 经 root 0600 临时文件传给 curl，不出现在命令行与输出中）。两个测试账号 `alice_demo`、`bob_demo` 的密码为随机生成，未记录。
> 本记录不含 token、cookie、密码或 Key。

## 验收中发现并修复的问题

- **非 UTF-8 请求体被静默接受**：第一次提交时，维护者 Windows 终端中的 curl 以 GBK 发送了中文主题；`encoding/json` 把非法字节替换为 U+FFFD，乱码主题被存下并交给模型。该任务已取消；修复（e360935）：所有 JSON 请求体先校验 UTF-8，非法即 `400 invalid_request`（RFC 8259 §8.1），并加了以 GBK 字节提交的回归测试。浏览器总是以 UTF-8 提交，不受影响。
