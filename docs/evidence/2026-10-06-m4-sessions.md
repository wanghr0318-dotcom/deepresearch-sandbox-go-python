# M4 会话后端验收记录（Plan 12 Task 9）

> 日期：2026-10-06。环境：WSL2（内核 6.6.87.2-microsoft-standard-WSL2，cgroup v2），PostgreSQL 16 与 Redis 7（docker compose）。
> 分支 `m4-p12-t9`（基于 `m4-batch` 6412e9d）。会话 Worker 为脚本化的 Go 程序 `tests/e2e/sessionworker`（CGO_ENABLED=0）；
> 真实模型的会话验收在 Plan 13 Task 9。

## 范围

- server 装配：`--turn-tool-budget`（30）、`--session-idle-freeze`（10m）、`--session-evict-after`（1h，须大于前者）、
  `--session-worker-argv`（空 = 会话端点 503 `sessions_unavailable`）；会话 actor ← coordinator/provider（Freeze/Thaw/Procs/RestoreDir）、
  runner incarnation、edge incarnation 入口（Attach/Detach，Detach 以 T_release 为界、先于 RevokeIncarnation）、admission
  MemoryOnly 与内存压力回调；启动顺序 恢复 → session Scheduler → task Scheduler → API。
- 重启恢复（E33）：会话环境（含 frozen）由计划的 StopEnv 停止，之后 `EvictSessionsOnRestart`；运行中 turn 的 attempt 为
  `lost_on_restart`（故障重试，下一次授予走冷恢复）。
- 不变量：I9（每会话至多一个非 ended incarnation；frozen 会话最近一次 quiesced 的 checkpoint = 会话指针，quiesced ID 随
  `session_state{frozen}` 的 payload 持久化）、I10（session checkpoint 只由 succeeded turn 提交；commit_seq 与指针单调）、I6 的 attempt 关联
  对 `seed-` 种子豁免。

## 结果

| 用例 | 内容 | 结果 |
|---|---|---|
| `TestSessionBasicFlow`（非 root） | 两条消息（第二条以第一条的会话 checkpoint 为 base，计数与 workspace 文件延续）；同一 incarnation；用户 B 读写 A 的会话一律 404；SSE seq 递增且用户视图无内部字段；存储 session_seq 连续；关闭后 workspace 删除、UID 范围归还 | 3/3 通过 |
| `TestToolBudgetAcrossRestart`（非 root） | 35 次搜索：第 31–35 次 429 `tool_budget_exhausted`，turn succeeded，`tool_calls_used = 30`；第 20 次之后 SIGKILL server 并重启，计数延续（重启后新建调用 ≤ 10） | 3/3 通过 |
| `TestSessionStopSupersedeRestore`（非 root） | stop → paused（`turn_stopped` 与之前事件可见）→ 新消息取代（`superseded`，turn 2 带 carryover）→ restore → turn 3 的首个 `task_start.resume` 为 `seed-…`，额度 30 | 3/3 通过 |
| `TestSessionAwaitingInput`（非 root） | `ask_user` → `awaiting_input`；`--run-slots 1` 下另一用户的 turn 照常完成（run slot 已归还）；answer → 同一 turn 以 `directive.answer{question_id}` 从提问前的 checkpoint 继续并成功 | 3/3 通过 |
| `TestRealE28SessionColdRestore`（root） | Worker 在 idle 时退出 → evicted → 新消息 → restoring → 冷恢复：同一 workspace、新 incarnation 与入口、同一 UID 范围；inline 与 state_ref 各一次，state_ref 从 `/run/agentbox/restore/<sha>` 读取，ready 后暂存目录删除，恢复期间连接 Gateway 被拒 | 4/4 通过 |
| `TestRealE29OutcomeLossAndReleaseTimeout`（root） | task_outcome 丢失一次 → 查询恢复，incarnation 继续服务；永不 task_released → `release_timeout` 销毁，turn 终态、会话指针、`fault_retries_used` 不变，不重跑 | 4/4 通过 |
| `TestRealE30LeakedChildFailsRelease`（root） | 释放前留下子进程 → 释放核验失败 → 销毁（环境内无进程）；T2 在新 incarnation 中运行；T1 无 T2 期间登记的调用 | 4/4 通过 |
| `TestRealE31FreezeAndFreezeFailure`（root） | `--session-idle-freeze 2s` → frozen（事件出现时 `cgroup.events` 为 `frozen 1`）→ thaw 后同一 incarnation 运行；`cgroup.events` 以 bind 替换为 `frozen 0` → 冻结未确认 → evicted（`freeze_failed`），不记录 frozen | 4/4 通过 |
| `TestRealE32CloseStopsEnvBeforeDeletingWorkspace`（root） | 暂停后 DELETE → turn cancelled → 环境 `stopped_at` 早于 workspace 删除 → closed、UID 范围归还 | 4/4 通过 |
| `TestRealE33RestartWithFrozenSession`（root） | frozen 会话时 SIGKILL server 并重启 → evicted、旧 incarnation `lost_on_restart`、冻结的旧环境停止并清理（cgroup 删除）→ 新消息冷恢复成功 | 4/4 通过 |

每个用例结束时 `verify-invariants --quiescent`（root 时为 `agentbox verify-invariants`）通过，含 I9、I10。
